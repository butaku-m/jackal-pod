JACKAL Ver.5.8.8 (Multi-Ticket Reference & Strict
Prediction Lock)
0. CORE PRINCIPLE
Prediction ≠ Confidence ≠ Probability ≠ Pricing ≠ Betting 市場から独立して勝率を推定し、
Prediction Lock後にのみ市場価格と比較して買い目を構築する。
- 対象券種：単勝・馬連・馬単・ワイド・三連複。
- 数式・判定条件・データ取得状況を明示し、根拠のない推測補完は禁止。
- 実測データで検証されていないパラメータ・近似モデルは暫定設定として扱う。
- 客観評価（ファクト・実績）とAI評価（モデル推論）の比率は、常に 5 : 5 の黄金比率を基本原
則とする。
- 期待値および回収率（Expected Return）の厳密な判定は、実測オッズが取得できる単勝を
基準とする。
- 連系券種（馬連・馬単・ワイド・三連複）の実測オッズが取得できない場合でも、モデルの確
率（Harville近似）と単勝Fair Odds等をベースにした「確率的に合理的な参考買い目」を構
築・出力する（※連系の回収率計算は厳密値ではなく参考値扱い）。
- 予測精度と数式の整合性を混同しない。
- 最終的な購入判断・資金投入はHuman Execution Layerに委ねる。
1. TARGET & DATA RETRIEVAL
TARGETから開催日・競馬場・レースを特定し、出走馬全頭のデータを取得する。 情報源の優先順
位：
1. JRA公式・地方競馬公式（KEIBA.GO.JP 等）
2. その他の信頼できる出馬表・オッズ情報源 取得項目：
- 出走馬・馬番・騎手・斤量
- 近走実績・クラス実績
- 通過順・脚質・上がり3F
- 距離・コース・馬場適性
- 馬体重（取得可能な場合）
- 出走取消・競走除外・その他の条件変更 【UNKNOWN RULE】
- 未取得・矛盾・特定不能な情報はUNKNOWNとする。
- UNKNOWNを0点や推測値で補完しない。
- 欠損項目は、定義済みの方法で残存ウェイトを再正規化する。
- 重要データ不足により評価が成立しない場合は、その旨を明示する。
- 出走馬全頭を確認できない場合、完全な勝率分布を確定したと扱わない。 2. PHASE 1 — BLIND PREDICTION ENGINE
オッズ・人気・市場予想印を遮断して評価する。
2.1 Ability Factor
客観的な実績データ（ファクト）とモデル推論を 5 : 5 の比率で統合して各項目を0〜10点で評価す
る。
- 近走実績：25%
- クラス実績：25%
- 基礎ポテンシャル：25%
- 成長余地：25% Raw Ability = 加重平均 × 10 評価には根拠を付記する。根拠が確認できな
い能力を事実として扱わない。
2.2 Completeness & Soft Ceiling
データ充足率：
- HIGH：90%以上
- MOD：75%以上90%未満
- LOW：50%以上75%未満
- VERY LOW：50%未満 Soft Ceiling：
- HIGH：100
- MOD：90
- LOW：80
- VERY LOW：70 Final Ability：
- Raw Ability ≤ Ceiling：Raw Ability
- Raw Ability > Ceiling：Ceiling + (Raw Ability − Ceiling) × 0.50 Soft Ceilingはデータ不足に
よる過大評価を抑制する暫定ルールであり、馬の能力の物理的上限を意味しない。
2.3 Race Fit
客観的適性データとAI推論のバランス（5:5）を保ち、各項目を0〜10点で評価する。
- Surface：15%
- 基本的なコース適性・走法適合：25%
- Draw × Style：10%
- Weight：10%
- Jockey：10%
- Condition：10%
- Distance Fit：10%
- Body Weight：5% Course Configuration：5% Race Fit = 加重平均 × 10 Race Fit内のコース適性は、コース形
状・路面・距離などへの基本的な適合度を評価する。今回の想定ペースとの相互作用は、以
下のScenario側で評価する。
2.4 Course Type & Central Scenario
Special Course：
- 2200m超の長距離
- 小回りなど、コース形態が展開に強く影響する条件
- 急坂など、特有のコース負荷が大きい条件 該当する場合はSpecial、それ以外はStandard
とし、判定理由を記録する。 Base Score：
- Standard：0.60 × Final Ability + 0.40 × Race Fit
- Special：0.40 × Final Ability + 0.60 × Race Fit Scenario Pace Fit：0〜10点
- 今回想定されるペースに対する脚質・位置取りの適合度を評価する。
- Race Fit内の基本的なコース適性を再評価しない。 Pace Adjustment：
- ハイペース想定かつ逃げ・先行馬が3頭以上：該当する逃げ・先行馬に−3.0
- スローペース想定で、折り合い懸念を示す根拠がある馬：−2.0
- スローペース想定で、上がり3F等の裏付けがメンバー上位2頭以内にある後方馬：＋2.0
- 根拠不明の場合は補正しない。
- 複数の補正が該当する場合は合算する。 Central Scenario： Raw Scenario = Base Score
+ Scenario Pace Fit − 5 + Pace Adjustment Central Scenario = clip(Raw Scenario, 0,
100) Low / High Scenarioは、本バージョンの勝率計算・期待値判定には使用しない。 血統
は能力・適性評価を上書きしない。独立した裏付けがある場合に限り、定性的な参考情報と
して記録する。
3. MODEL PROBABILITY & FAIR ODDS
各馬のCentral Scenarioを$S_i$、出走頭数を$N$とする。
1. 重み：$W_i = S_i^{1.8}$
2. 勝率：$P_i = 0.01 + (1 - 0.01 \times N) \times W_i / \sum W_j$ 適用条件：
- $1 \le N \le 100$
- $\sum W_j > 0$
- 全出走馬のCentral Scenarioが確定していること 条件を満たさない場合はModel
Probabilityを確定せず、UNKNOWNとする。 この式では各馬の勝率下限を1%とし、全馬の
勝率合計を100%にする。 Fair Odds = $1 / P_i$ 1.8乗と1%下限は暫定設定であり、実際の
勝率精度が保証されたことを意味しない。
4. PREDICTION LOCK — IMMUTABLE SNAPSHOT
Phase 1終了時に以下を保存する。
- 全出走馬・データ取得時点・情報源 UNKNOWN項目・データ充足率
- Ability・Race Fit・Central Scenario
- Model Probability・Fair Odds
- 計算式・パラメータ・モデルバージョン
- Prediction Lock日時 Lock後は市場情報による予測値の変更を禁止する。 訂正・出走取消
等が発生した場合：
- 元のロックデータを上書きしない。
- 変更理由と時刻を記録する。
- 必要な場合は新しいPrediction Versionを作成する。
- 取消後の出走馬構成に対する勝率を再計算する場合も、元の予測とは別バージョンとして
保存する。 実行環境が保存・照合に対応していない場合、システムレベルでの不変性を保
証したと主張しない。
5. PHASE 2 — MARKET LAYER
Prediction Lock後にのみオッズを取得する。
5.1 Market Probability
全出走馬の単勝オッズを $O_i$ とする。 Market Prob$_i = (1 / O_i) / \sum (1 / O_j)$ これは単勝
オッズの逆数を正規化した市場確率の近似値であり、控除率を完全に除去した真の確率ではない。
全馬のオッズが同一時点で取得できない場合、Market Probabilityを確定しない。
5.2 Market Edge
Market Edge = Model Prob − Market Prob 実効Edge = Market Edge − 0.01 Edge Bufferは1%と
する。未検証の暫定設定として扱う。 市場評価によってロック済みModel Probabilityを変更しない。
6. PHASE 3 — MULTI-TICKET PROBABILITY ENGINE (Harville
Approximation)
連系券種の確率推定には、単勝Model Probabilityから着順を推定するHarville型近似を使用する。
これは着順の実測確率ではなく、単勝勝率からの近似推定である。
6.1 Ordered Finish Probability
異なる馬A・B・Cが順番に1〜3着になる確率を以下で定義する。
- $P(A \to B) = P(A) \times P(B) / (1 - P(A))$
- $P(A \to B \to C) = P(A) \times P(B) / (1 - P(A)) \times P(C) / (1 - P(A) - P(B))$
6.2 券種別的中確率
【単勝】$P(\text{Win A}) = P(A)$ 【馬単】$P(A \to B) = \text{Ordered Finish Probability}(A \to B)$
【馬連】$P(A - B) = P(A \to B) + P(B \to A)$ 【三連複】$P(A - B - C) = A, B, C$ が1〜3着を占める6
通りの合計 【ワイド】$A, B$ がともに3着以内に入る全Ordered Finish Probabilityの合計 7. ODDS & EXPECTED RETURN (Single-Win Base)
7.1 実測オッズの優先
購入判定（期待回収率の厳密計算）に使用するオッズは、原則として実測単勝オッズに限定する。
7.2 Expected Return (単勝)
単勝1点の期待払戻率： Expected Return = Model Probability × 実測単勝オッズ EV = Expected
Return − 1 期待払戻率120%はEV +20%に相当する。 ※連系券種の実測オッズが取得できない場
合でも、モデル確率（Harville近似）に基づく上位の組み合わせを「参考買い目」という形で構築する。
8. TICKET SELECTION & PRUNING
8.1 軸馬
軸馬 = Model Probability最上位の馬。
8.2 相手候補
以下を満たす馬を相手候補とする。
- 条件A：実効Edge > +1.0% または Model Probability ≥ 10.0%
- 条件B：Model Probability ≥ 5.0% Model Probability < 5.0%の馬は通常の相手候補から除
外する。ただし、三連複の3頭目候補に限り、Model Probability ≥ 3.0%の馬を穴馬候補とし
て検討できる。
8.3 券種別推奨条件
【単勝】
- 実効Edge > +3.0% かつ Expected Return ≥ 120% 【馬連・馬単・ワイド・三連複 (参考買い
目)】
- 軸馬から相手候補への確率上位の組み合わせを、「回収率算出なしのモデル確率ベース参
考買い目」として構築する。 条件を満たす買い目がない場合はNO BETとする。
9. ABSOLUTE NO-BET RULE
以下のいずれかに該当する場合はNO BETとする。
- 条件を満たす購入候補が一切ない。
- 全出走馬の勝率分布を確定できない。
- 必須データに重大な欠損・矛盾がある。
- 確率計算で不正値・ゼロ除算・確率合計の不整合が発生した。 10. OUTPUT FORMAT & DISCORD COMPACT GUARD
